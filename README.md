# for-ts-and-angular
Angular — это платформа для разработки, написанная на TypeScript. Как платформа Angular включает:
1)Основанный на компонентах фреймворк для создания масштабируемых веб-приложений
2)Набор хорошо интегрированных библиотек, охватывающих широкий спектр функций: маршрутизация, управление формами, клиент-серверное взаимодействие и т.д.
3)Набор инструментов разработчика, которые помогут вам разрабатывать, собирать, тестировать и обновлять ваш код

Полезно знать по своему личному опыту:

ng build	Компилирует Angular-приложение в выходной каталог(в целом это основа если так можно сказать).

ng serve	Собирает и запускает ваше приложение, пересобирая его при изменении файлов.

ng generate	Генерирует или изменяет файлы на основе схематиков

ng test	Запускает модульные тесты для заданного проекта.

ng e2e	Собирает и запускает Angular-приложение, запуская затем сквозные тесты.

Что из прикольного так это что ангулар запускается с локалхоста 4200 

Файлы, генерируемые CLI автоматически, на которые стоит обратить внимание:
app.module.ts: определяет файлы, которые использует приложение. Этот файл действует как центральный узел для других файлов в вашем приложении.
app.component.ts: Определяет класс, который содержит логику основной страницы приложения.
app.component.html: Содержит HTML для AppComponent. Содержимое этого файла также называется шаблоном. Шаблон определяет представление или то, что вы видите в браузере.
app.component.css: Содержит стили для AppComponent. Этот файл используется, когда вам нужно стилизовать определённый компонент, а не всё приложение.
Для ссылки на внешний html-файл, используется свойство templateUrl:

js
@Component({
  selector: "app-root",
  templateUrl: "./app.component.html",
})
export class AppComponent {}
либо же если кто нибудь захочет указать напрямую html-код, используется свойство template с обратными кавычками:

js
@Component({
  selector: "app-root",
  template: `<h1>Hi!</h1>`,
})
export class AppComponent {}

Angular расширяет html дополнительным синтаксисом, который позволяет вставлять динамические данные в компонент. Angular автоматически обновляет DOM, когда состояние компонента изменяется. Например, этот синтаксис можно применить для вставки динамического текста, как показано в следующем примере.

<h1>{{ title }}</h1>


Компонент может наследовать общие стили приложения из файла styles.css или переопределять их собственными стилями. Ты можете писать стили для конкретных компонентов прямо в декораторе @Component() или указывая путь к css-файлу.

Чтобы включить стили непосредственного в декоратор компонента, используется свойство styles:

js
@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styles: ['h1 { color: red; }']
})


Обычно компонент использует стили определяемые в отельном файле, указанном в свойстве styleUrls:

js
@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.css']
})
